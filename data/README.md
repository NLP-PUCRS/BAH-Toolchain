# Data Directory Structure

This directory stores audio datasets, extracted representations, and intermediate evaluation artifacts.

```
data/
├── Audios/                 # Place raw, unorganized audio files here (e.g., VERBO dataset)
│   ├── f01/
│   │   ├── ale-f01-s01.wav
│   │   └── ...
│   └── m01/
│       ├── ale-m01-s01.wav
│       └── ...
│
├── raw/                    # Audio files organized by dataset and emotion class
│   └── verbo/
│       ├── ale/            # Alegria (Joy)
│       ├── des/            # Desprezo (Contempt)
│       ├── med/            # Medo (Fear)
│       ├── neu/            # Neutro (Neutral)
│       ├── rai/            # Raiva (Anger)
│       ├── sur/            # Surpresa (Surprise)
│       └── tri/            # Tristeza (Sadness)
│
├── features/               # Pre-extracted .npy feature representations
│   └── <feature_name>/     # e.g., hubert, whisper, wav2vec2, eGeMAPSv02_88, etc.
│       └── <dataset>/      # e.g., verbo
│           └── <class>/    # e.g., ale, des, med, neu, rai, sur, tri
│               └── <audio_id>.npy
│
└── processed/              # Generated metadata and predictions
    ├── verbo.csv           # Metadata generated by pre_processing_VERBO.py
    └── predicted/
        └── Soft_Voting/    # Saved test predictions (.npy) for late fusion ensembling
```

## Dataset Pre-Processing Workflow
1. Place audio files in `data/Audios/`.
2. Run the pre-processing script to organize audio into class folders and generate metadata:
   ```bash
   python scripts/pre_processing_VERBO.py
   ```
3. Extract acoustic and SSL feature representations into `data/features/`.
4. Run the evaluation pipeline with `./run.sh` or `python scripts/evaluate.py`.
